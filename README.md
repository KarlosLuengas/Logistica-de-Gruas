# Proyecto Gruas

Desarrollado para el gobierno del estado de Puebla, este sistema logístico está diseñado para registrar y gestionar accidentes viales. 

## Incluye

- Registro de ubicaciones y corralones con generación de códigos únicos para los afectados.
- Integración con Google Maps API: Permitía trazar rutas desde el lugar del accidente hasta el corralón más cercano, rellenando automáticamente información clave.
  
## Tecnologías destacadas

### Front-end
- HTML
- Bootstrap 
- JavaScript
- CSS
### Back-end
- PHP
### APIs
- API de Google Cloud.
